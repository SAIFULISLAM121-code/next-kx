# Student Attendance Manager

A responsive Next.js dashboard for managing a classroom roster and daily attendance.

## Features

- Starts with Aman (71%), Saif (89%), and Priya (99%).
- Search and filter students by attendance.
- Add students and mark daily attendance.
- Export the roster and attendance statuses as a CSV file.
- Save changes in the current browser using local storage.

This starter app stores data locally in the browser; it does not include a server, accounts, or cross-device sync.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```
